## The rules these captions follow

| Practice | How it's applied |
|---|---|
| **The hook fits before "…more"** | Instagram shows roughly the first 125 characters. Every first line is a complete hook within that limit (checked; see the length column). LinkedIn cuts off around 210 characters, so the first two lines carry the point. |
| **One CTA per post** | Each post asks for one action: save, share, comment or DM. Asking for several at once lowers the response to each. |
| **DM keywords** | Conversion posts ask for a DM with a keyword (START, SYSTEM, FILM…). The keyword shows which post produced the lead, and DMs count as strong engagement. Log each one. |
| **Mix of CTAs** | Save prompts on teaching posts (06), share/tag prompts on relatable posts (02, 10), comment prompts on opinion posts (03, 09), DMs on offer posts (04, 05, 08, 11, 12). |
| **Searchable words** | Instagram search reads captions, so each caption names what AURIC does in plain words (website, video, brand film, ERP, law firm, real estate). |
| **3–5 hashtags, specific** | Niche hashtags in the first comment or at the end of the caption. No banks of 30. |
| **Short lines, white space** | One idea per line. Plain arrows instead of emoji walls. |
| **No links in Instagram captions** | They aren't clickable: use "link in bio" and Story link stickers. On LinkedIn the link goes in the first comment, because posts with external links get less reach. |
| **Alt text on every image** | Under "Advanced settings → Accessibility". Describes what's in the image for screen readers and helps search. |
| **Honest** | Real projects with their real status (client project / AURIC product / showcase build). The illustrative example is labelled as one. No numbers or quotes that aren't verified. |
| **Answer fast** | Reply to every comment and DM in the first hour after posting. That's when the algorithm decides how widely to show the post. |

**Post 07 is retired:** AURIC does not offer VR, so it is not scheduled. Post 03 lists Data in place of VR. Arabic versions of the captions should come from a native writer.

### Instagram caption

```
Before we design anything, we ask four questions. Save this for your next brief.

One clear audience. "Everyone" is not an audience.
```
